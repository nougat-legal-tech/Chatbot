## Notable patterns or gotchas
- `/api` CJS wiring layer must stay thin: behavior belongs in `packages/api` TS modules (`AGENTS.md`)
- Database contracts in `packages/data-schemas`; Mongoose types must not leak into `packages/api` or client exports
- Client state migrating Recoil → Jotai; new state always Jotai, pass app-global state via props/context
- `createModels(mongoose)` must run before `indexSync` module load or MeiliSearch sync silently fails (`api/db/index.js:10`)
- `JURISTAI_ENSURE_AGENT_ACTION` boot-enforces agent-to-django-tools binding; non-fatal if agent missing
- MCP server is vendored copy from `django-hub/mcp_server`; manual re-sync required until cross-repo mechanism exists
