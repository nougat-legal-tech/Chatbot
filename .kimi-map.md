## Notable patterns or gotchas
- `/api` CJS wiring holds minimal behavior per AGENTS.md; logic belongs in `packages/api` TS modules
- Database contracts isolated to `packages/data-schemas`; Mongoose types must not leak into `packages/api` or client exports
- Client state migrating Recoil→Jotai; new state always Jotai, pass app-global Recoil atoms via props/context
- MCP OAuth flow managers use singleton pattern with Redis-backed `evalKeyvRedisScript` for distributed state
- Boot-time `ensureJuristaiAgentAction` enforces agent-action binding idempotently; non-fatal if agent missing
- GenerationJobManager has graceful shutdown with `SHUTDOWN_TEARDOWN_RESERVE_MS=10000` budget for detached generations
- Vite build uses `rolldownOptions` with extensive manual chunking for vendor splitting
- `docker-compose.yml` exposes port 8001 for MCP server sidecar; `mcp_server/Dockerfile` is vendored copy from django-hub repo
